# Horizon — atualizações oficiais

Este repositório público é usado exclusivamente pelo atualizador automático do aplicativo Horizon para Windows.

## Segurança

- Não contém código-fonte.
- Não contém arquivos `.env`, tokens, senhas ou credenciais.
- Os instaladores e manifestos são publicados na área **Releases**.

> Baixe o Horizon somente pelas versões publicadas neste repositório oficial.
